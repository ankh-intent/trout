Connect a client to this relay

Point the client's OpenAI-compatible base URL here and add two headers. The provider key stays in Authorization and is passed through untouched.

Base URL
https://<this-relay>/v1
X-Trout-Key
This relay's access key.
X-Trout-Target
Your provider's base URL with its version prefix, e.g. https://api.example.com/v1.
curl -s https://<this-relay>/v1/chat/completions \
  -H "X-Trout-Key: $TROUT_KEY" -H "X-Trout-Target: $TARGET" \
  -H "Authorization: Bearer $API_KEY" -H 'Content-Type: application/json' \
  -d "{\"model\":\"$MODEL\",\"messages\":[{\"role\":\"user\",\"content\":\"hi\"}]}"
